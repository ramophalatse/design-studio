Level 1The Enthusiast

Claude as a search bar that returns paragraphs

Open Claude, ask a question, get an answer, close the tab. Emails, quick scripts, explanations. Useful : but it's the floor, saving maybe 30 minutes a day.

Quick win most people missPaste screenshots

Claude reads images. Half the people stuck here type out what a screenshot would show in two seconds.

Why people stay stuckNo continuity

They don't realise Claude can hold context across chats, organise work into projects, or plug into the tools they already use.

Cheat code → Level 2

Create your first project : pick recurring work, drop in reference docs, write a short system prompt. Every chat now starts preloaded.

Level 2The Beginner

Projects are the spine : everything stacks on them

01Memory + past chat search

Claude recalls your role, preferences and past decisions. Memory is free; searching past chats is paid.

02Connectors (50+)

Slack, Drive, Gmail, GitHub, Notion, Calendar : OAuth in, stop pasting, start asking.

03File creation

Real Excel files with working formulas, decks, Word docs and PDFs : deliverables, not previews.

04Artifacts 2.0

Persistent storage, can call Claude's API, publishable links : a non-coder ships a working team tool by lunch.

05Inline visuals

Ephemeral charts and diagrams that live in the chat and update as the conversation evolves.

06Office add-ins

Claude inside Excel, PowerPoint and Word : with shared context across all three since April 2026.

The ceiling

Claude still can't act on your machine : you're copying outputs and executing changes yourself.

Cheat code → Level 3

Stop making chat do everything : open Claude Desktop and click the Cowork tab.

Level 3The Intermediate : Cowork

"I wish Claude could just go do this on my computer"

Point Cowork at a chaotic downloads folder, ask it to sort, rename and summarise : then go make coffee. Paid plans only. This is where 10+ hours a week comes back.

01File system access

Runs in an isolated VM with real read/write on folders you grant. It owns what you permit, nothing else.

02Skills

Reusable workflows as markdown files. 100+ published, 16+ official, plus a community marketplace. Build once, run in chat, Cowork and Code.

03Scheduled tasks

/schedule any cadence : machine must be awake. Cloud-based routines come at Level 5.

04Mobile dispatch

Pair your phone : send tasks from the gym or a meeting, get pinged when Claude's done.

05Claude Design

Describe a prototype or deck in plain English; it reads your brand and builds a design system, then packages a handoff bundle.

+Plugins + computer use

One-click bundles of skills and connectors; visual navigation of apps with no connector, on Mac and Windows.

Cheat code → Level 4

Give Claude a folder structure it can rely on : about-me file, templates, projects, outputs : with standing rules for each.

Level 4The Advanced : Claude Code

Five parallel Claudes, zero conflicts

Boris Cherny, who built Claude Code, runs five isolated sessions daily and returns to completed pull requests. The Code tab in Desktop runs the same engine : no terminal required.

01CLAUDE.md

Read at the start of every session : keep it under ~200 lines. The key habit : every mistake, say "update your CLAUDE.md so this never happens again."

02Plan mode

Shift+Tab twice : Claude reads, plans, waits for approval. Opus Plan setting : Opus plans, Sonnet executes, roughly half the cost.

03Sub-agents

Specialised Claudes for tests, security, docs : each in its own context window, running in parallel.

04Worktrees

Isolated Git workspaces per feature : three to four parallel Claudes is the sweet spot.

05MCP, with an asterisk

The hierarchy : CLI first, API second, skills third, MCP only when nothing else fits. CLIs use 60-70% fewer tokens; tool search cuts MCP overhead ~85%.

$What it's worth

This is where freelance and agency work becomes $5-15k systems : real software, not just automations.

Level 4Power moves

Context discipline + a verification loop

Context/compact + /context

Sessions get sloppy past ~50% of the window : compact proactively, audit where tokens go. With prompt caching, long-session costs drop 60-90%.

FlowAuto mode + /focus

Stop approving 30 times a session; hide intermediate steps. This is how five parallel sessions stay manageable.

QualityVerification loop

Give Claude a way to check its own work : browser testing, screenshots, no POC until self-tested. Cited as a 2-3x quality multiplier.

ReuseCustom /commands

Typed the same prompt twice? Make it a slash command in .claude/commands and share it with your team.

Side tools/rewind /btw /branch

Drop failed attempts from context, ask quick questions without noise, fork the conversation : Git for your reasoning.

Self-audit/insights + output styles

A monthly report on your own usage patterns; swap Claude Code's personality per job.

The stall

Managing all the parallel work manually : you become the bottleneck, babysitting sessions.

Cheat code → Level 5

Find your most repetitive weekly task in Claude Code : that becomes your first automation.

Level 5The Architect

Work that happens while your laptop is closed

A PR opens on your repo; Claude spins up in the cloud, reviews it and posts feedback before you've checked your phone. Claude stops being a tool and becomes infrastructure.

01Routines

Saved Claude Code configs running on Anthropic's cloud : triggered by schedule, API call or GitHub event. Your machine stays off.

02Hooks

Safety rails at lifecycle events : block dangerous commands pre-run, auto-format post-edit, ping Slack on completion.

03Channels

Drive sessions from Discord, Telegram or iMessage : one-way triggers or two-way texting against a real codebase.

04Headless + Agent SDK

claude -p with no human session; Python and TypeScript libraries to build products on the engine. User becomes builder.

05Memory + budgets

Auto dream prunes and merges memory between sessions; task budgets (API beta) let agents self-regulate token spend and wrap up gracefully.

06Agent teams

Experimental : specialised Claudes with a lead agent, a shared task list, and the ability to debate each other. Token-hungry but powerful.

Level 5The real stall

The barrier isn't technical : it's trust

Almost anyone can set up a cloud routine. Most won't, because handing the wheel to a system that runs while you sleep feels reckless. The fix is the same as learning to drive : start in the parking lot, not on the highway.

Start low-stakesInternal-only first

A daily stand-up summary that goes only to you. A weekly dependency audit. Nothing sent externally.

Build the repsWatch, don't touch

Let routines run for weeks. Each trusted run earns trust for the next ten.

Match autonomy to riskDeterministic first

Move-data-from-A-to-B automations are trustworthy by nature; agentic routines are more powerful but need careful, gradual rollout.

The takeaway

From brilliant intern to standing infrastructure

Chat

An intern with no memory. ~30 min/day saved.

Projects

The intern remembers everything and hands you finished files. 5+ hrs/week.

Cowork

A real co-worker on your machine. 10+ hrs/week : the minimum bar for selling automation.

Claude Code

An engineering team in parallel : $5-15k client systems.

Architect

Always-on infrastructure that works while you sleep.

The discovery habit matters as much as the build habit : thousands of community skills, MCP servers and marketplaces already exist. Leverage before you build : then customise.
